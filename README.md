## Install

**Mac.** Open the downloaded `.pkg`. The first time, macOS says it can't verify the developer: click **Done**, open **System Settings → Privacy & Security**, click **Open Anyway**, then open the file again. BackLab installs into Applications and opens.

**Windows.** Open `BackLab-windows-setup.exe`. If you see *Windows protected your PC*, click **More info → Run anyway**. BackLab installs and opens by itself.

BackLab keeps itself up to date after that.

**Connect it to your account.** Sign in at [backlab.trade](https://backlab.trade/#download) and press **Connect this computer**.
